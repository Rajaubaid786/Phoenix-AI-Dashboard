## 🚀 Key Features

| Feature | Description |
|---|---|
| 📊 **Live Analytics Dashboard** | Real-time monitoring of MRR, total clients, and active AI systems |
| 📈 **Dynamic Revenue Flow** | Responsive `AreaChart` visualizing business growth with natural growth curves |
| 👥 **Advanced Client CRM** | Full CRUD table with global search, category filters (Paid/Pending), and AI status tracking |
| 🤖 **AI System Infrastructure** | Dedicated monitoring for Retell AI Agents — latency, model types, and deployment status |
| ⚡ **Live Activity Feed** | High-speed system log with one-click **Clear All** to keep your workspace clean |
| 🔍 **Global Search & Filtering** | Instantly find any client or system across the entire platform from the top nav |
| 🌑 **Professional Dark UI** | High-end SaaS feel with Tailwind CSS and Framer Motion for smooth animations |

## 🏁 Getting Started

### Prerequisites

- Node.js `v18+`
- npm or yarn

### Installation

**1. Clone the repository:**

```bash
git clone https://github.com/Rajabaid786/Phoenix-AI-Dashboard.git
cd Phoenix-AI-Dashboard
```

**2. Install dependencies:**

```bash
npm install
```

**3. Run the development server:**

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
